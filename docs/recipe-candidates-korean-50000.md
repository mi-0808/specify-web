- ポコポコシャギーラグは、**アイボリーが在庫切れ**（ベージュ・グレー・ピンクは在庫あり）。

- ニトリの商品は、一覧の URL（末尾が `s`）と色・サイズ別の URL がある。レシピには色・サイズ別の URL を使う。
- 無印良品では、今回の候補にした商品はない。
